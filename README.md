# Ayaan Ahmad — Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the Pages deployment to finish.

The expected site address is https://ayaanayu.github.io/ayaan-ahmad-portfolio/.

## Customize

Update `index.html` to add verified contact details, LinkedIn, more project details, and project links when available.
