## 💻 Run Locally

This is a static website and does not require a build process or package installation.

1. Clone the repository:

   ```bash
   git clone https://github.com/ayaanayu/ayaan-ahmad-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd ayaan-ahmad-portfolio
   ```

3. Open `index.html` in your browser.
